# Getting Started

AINativeKit UI extends [@openai/apps-sdk-ui](https://github.com/openai/apps-sdk-ui) with production-ready patterns for ChatGPT Apps.

## Installation

```bash
npm install @ainativekit/ui @openai/apps-sdk-ui
```

## Setup

Import the styles in your app's entry point:

```tsx
// Import OpenAI Apps SDK UI styles (base design system)
import '@openai/apps-sdk-ui/css';

// Import AINativeKit UI styles
import '@ainativekit/ui/styles';
```

## Quick Start

```tsx
import { SummaryCard } from '@ainativekit/ui';
import { StarFilled, Clock } from '@openai/apps-sdk-ui/components/Icon';

function RestaurantCard({ restaurant }) {
  return (
    <SummaryCard
      images={restaurant.image}
      title={restaurant.name}
      subtitle={restaurant.address}
      description={restaurant.description}
      metadata={[
        { icon: <StarFilled />, label: restaurant.rating },
        { icon: <Clock />, label: 'Open now' }
      ]}
      buttonText="Reserve"
      onButtonClick={() => {}}
    />
  );
}
```

## Design Tokens

AINativeKit UI inherits all design tokens from `@openai/apps-sdk-ui`:

- **Colors**: `--color-*`, `--gray-*`
- **Typography**: `--font-*`, `--text-*`
- **Spacing**: `--spacing`
- **Radius**: `--radius-*`
- **Shadows**: `--shadow-*`

See the [apps-sdk-ui Storybook](https://openai.github.io/apps-sdk-ui) for the complete token reference.

## Icons

Use icons directly from `@openai/apps-sdk-ui`:

```tsx
import { StarFilled, MapPin, Clock } from '@openai/apps-sdk-ui/components/Icon';

<StarFilled />
<MapPin />
<Clock />
```

All 417 icons are available. See the [apps-sdk-ui Icon gallery](https://openai.github.io/apps-sdk-ui) for the complete list.

## TypeScript

Full TypeScript support with exported types:

```tsx
import type { LocationData } from '@ainativekit/ui';
import type { Album, Photo } from '@ainativekit/ui';
```
