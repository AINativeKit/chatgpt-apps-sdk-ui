# Design Tokens

AINativeKit UI uses CSS custom properties (design tokens) for consistent theming.

## Base Tokens (from apps-sdk-ui)

We inherit all design tokens from `@openai/apps-sdk-ui`. These provide the foundation for colors, typography, spacing, and more.

### Spacing

The base spacing unit is `--spacing` (4px). Use with `calc()`:

```css
padding: calc(var(--spacing) * 2);  /* 8px */
margin: calc(var(--spacing) * 4);   /* 16px */
gap: calc(var(--spacing) * 3);      /* 12px */
```

## Breakpoints

We provide CSS breakpoints for responsive layouts:

<table>
  <thead>
    <tr>
      <th>Breakpoint</th>
      <th>Value</th>
      <th>Usage</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>xs</code></td>
      <td>380px</td>
      <td>Small mobile</td>
    </tr>
    <tr>
      <td><code>sm</code></td>
      <td>576px</td>
      <td>Mobile / ChatGPT Widget</td>
    </tr>
    <tr>
      <td><code>md</code></td>
      <td>768px</td>
      <td>Tablet</td>
    </tr>
    <tr>
      <td><code>lg</code></td>
      <td>1024px</td>
      <td>Desktop</td>
    </tr>
    <tr>
      <td><code>xl</code></td>
      <td>1280px</td>
      <td>Large desktop</td>
    </tr>
    <tr>
      <td><code>2xl</code></td>
      <td>1536px</td>
      <td>Extra large</td>
    </tr>
  </tbody>
</table>

Use the `useBreakpoint` hook from apps-sdk-ui:

```tsx
import { useBreakpoint } from '@openai/apps-sdk-ui/hooks/useBreakpoints';

function MyComponent() {
  const { current, atLeast, atMost } = useBreakpoint();

  return (
    <div>
      {atMost('sm') && <MobileLayout />}
      {atLeast('md') && <DesktopLayout />}
    </div>
  );
}
```

## Customization

Override tokens in your app's CSS:

```css
:root {
  /* Customize card appearance */
  --card-radius: var(--radius-lg);
  --card-shadow: var(--shadow-200);

  /* Customize modal size */
  --modal-width: 480px;
  --modal-max-height: 80vh;
}
```

For theme-specific overrides:

```css
[data-theme="dark"] {
  --map-popup-background: var(--gray-900);
}
```
