## Usage

```tsx
import { Sidebar } from "@ainativekit/ui";

function MyComponent() {
  const [open, setOpen] = useState(false);

  return (
    <div style={{ position: 'relative' }}>
      <button onClick={() => setOpen(true)}>Open</button>
      <Sidebar open={open} onClose={() => setOpen(false)}>
        <YourContent />
      </Sidebar>
    </div>
  );
}
```

## Notes

- The sidebar uses `position: absolute`, so it should be placed inside a container with `position: relative`
- For responsive layouts, consider using `Modal` for mobile and `Sidebar` for desktop
- The close button is not included by default - add your own in the children content
