## Item structure

Each item in the `items` array should have:

<table>
  <thead>
    <tr>
      <th>Property</th>
      <th>Type</th>
      <th>Required</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><span className="type-hint">`id`</span></td>
      <td>`string`</td>
      <td>Yes</td>
      <td>Unique identifier</td>
    </tr>
    <tr>
      <td><span className="type-hint">`title`</span></td>
      <td>`string`</td>
      <td>Yes</td>
      <td>Item title (also used for avatar initials)</td>
    </tr>
    <tr>
      <td><span className="type-hint">`image`</span></td>
      <td>`string`</td>
      <td>No</td>
      <td>Avatar image URL</td>
    </tr>
    <tr>
      <td><span className="type-hint">`metadata`</span></td>
      <td>`string`</td>
      <td>No</td>
      <td>Secondary text above title (e.g., date, role)</td>
    </tr>
    <tr>
      <td><span className="type-hint">`description`</span></td>
      <td>`string`</td>
      <td>No</td>
      <td>Description text below title</td>
    </tr>
  </tbody>
</table>
