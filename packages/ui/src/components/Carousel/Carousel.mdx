## Usage

```tsx
import { Carousel } from "@ainativekit/ui";

<Carousel>
  {items.map((item, i) => (
    <div key={i} style={{ width: '320px', flexShrink: 0 }}>
      <Card>{item.content}</Card>
    </div>
  ))}
</Carousel>
```

**Important:** Each slide must have an explicit width and `flexShrink: 0` to prevent size changes during scrolling.

## Loading State Best Practice

Pass `loading` to both the Carousel and individual cards for seamless transitions:

```tsx
<Carousel loading={isLoading}>
  {items.map((item, i) => (
    <div key={i} style={{ width: '240px', flexShrink: 0 }}>
      <ImageCard
        loading={isLoading}
        image={item.image || ''}
        title={item.title || ''}
        size="compact"
      />
    </div>
  ))}
</Carousel>
```

Cards maintain their exact size during the loading state, preventing layout shift.

## Technical Notes

**Dependencies:**
- `embla-carousel-react` - Touch/swipe carousel
- `embla-carousel-wheel-gestures` - Mouse wheel support

**Accessibility:**
- Navigation buttons have proper aria-labels
- Keyboard navigation supported (Tab to buttons, Enter to activate)
- Swipe gestures work with touch devices
- Edge gradients have `aria-hidden="true"`

**Performance:**
- Uses CSS transforms for smooth 60fps scrolling
- Lazy load images inside cards for faster initial render
- Avoid heavy computations in slide change callbacks
