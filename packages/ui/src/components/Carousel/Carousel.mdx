## Usage

```tsx
import { Carousel } from "@ainativekit/ui";

<Carousel>
  {items.map((item, i) => (
    <div key={i} style={{ width: '320px', flexShrink: 0 }}>
      <ImageCard image={item.image} title={item.title} size="compact" />
    </div>
  ))}
</Carousel>
```

**Important:** Each slide must have an explicit width and `flexShrink: 0`.

## Technical Notes

**Dependencies:** `embla-carousel-react`, `embla-carousel-wheel-gestures`

**Accessibility:** Navigation buttons have aria-labels, keyboard navigation supported, touch/swipe enabled.
