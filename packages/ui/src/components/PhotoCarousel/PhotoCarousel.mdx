## Usage

```tsx
import { PhotoCarousel } from "@ainativekit/ui";
import { Overlay } from "@ainativekit/ui";

<PhotoCarousel
  images={['photo1.jpg', 'photo2.jpg', 'photo3.jpg']}
  aspectRatio="16/9"
  topOverlay={
    <Overlay background="#0066CC" height={32} align="center">
      <span style={{ color: 'white' }}>Brand</span>
    </Overlay>
  }
/>
```

## Notes

- Built on [Embla Carousel](https://www.embla-carousel.com/)
- Touch and mouse swipe support
- Lazy loading for performance
- Keyboard navigation support
- Used internally by SummaryCard for multi-image display
