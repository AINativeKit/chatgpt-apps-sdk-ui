## Usage

```tsx
import { CompactMap, FullscreenMap } from "@ainativekit/ui";

// Use a preset provider
<CompactMap locations={locations} tileProvider="carto-voyager" />

// Or provide custom configuration
<CompactMap
  locations={locations}
  tileProvider={{
    url: 'https://your-tiles.com/{z}/{x}/{y}.png',
    attribution: '© Your Company',
    maxZoom: 19,
  }}
/>
```

All tile providers shown below are **free to use** (no API key required). Retina/high-DPI support is enabled by default.

## Premium Providers (API Key Required)

Additional tile providers are available that require API keys. All offer generous free tiers:

| Provider | Styles | Sign Up |
|----------|--------|---------|
| **Stamen Design** (via Stadia Maps) | `stamen-toner`, `stamen-terrain`, `stamen-watercolor` | [Stadia Maps](https://client.stadiamaps.com/signup/) |
| **Geoapify** | `geoapify-osm-bright-grey`, `geoapify-osm-bright-smooth` | [Geoapify](https://www.geoapify.com/) |
| **Thunderforest** | `thunderforest-transport`, `thunderforest-landscape` | [Thunderforest](https://www.thunderforest.com/) |

```tsx
// Example: Using Stamen Watercolor with API key
<CompactMap
  locations={locations}
  tileProvider="stamen-watercolor"
  tileApiKey={process.env.REACT_APP_STADIA_MAPS_KEY}
/>
```
