## Usage

```tsx
import { CompactMap, FullscreenMap } from "@ainativekit/ui";

// Use a preset provider
<CompactMap locations={locations} tileProvider="carto-voyager" />

// Or provide custom configuration
<CompactMap
  locations={locations}
  tileProvider={{
    url: 'https://your-tiles.com/{z}/{x}/{y}.png',
    attribution: '© Your Company',
    maxZoom: 19,
  }}
/>
```

All tile providers shown below are **free to use** (no API key required). Retina/high-DPI support is enabled by default.
