## Usage

```tsx
import { Map, CompactMap, FullscreenMap } from "@ainativekit/ui";
import type { LocationData } from "@ainativekit/ui";

const [isFullscreen, setIsFullscreen] = useState(false);

<Map
  locations={locations}
  isFullscreen={isFullscreen}
  onToggleFullscreen={setIsFullscreen}
/>
```

Built on Leaflet with interactive markers, map place cards, multiple layout options, and integrated support for ChatGPT Apps SDK.

**Key Features:**
- Three component variants: Map (orchestrator), CompactMap (inline), FullscreenMap (full-featured)
- Interactive markers with popups and custom rendering
- Location carousel with synchronized selection
- Inspector panel with detailed information
- Loading, error, and empty states built-in
- Responsive design and SSR-safe

## ChatGPT Apps SDK Integration

The Map component works seamlessly with ChatGPT Apps SDK. Use controlled mode for iframe expansion:

```tsx
const [isMapFullscreen, setIsMapFullscreen] = useState(false);

const handleMapToggle = (fullscreen: boolean) => {
  setIsMapFullscreen(fullscreen);
  // ChatGPT SDK will expand/collapse the iframe
};

<Map
  locations={locations}
  isFullscreen={isMapFullscreen}
  onToggleFullscreen={handleMapToggle}
/>
```

**Key Points:**
- Use controlled mode (`isFullscreen` + `onToggleFullscreen`) for ChatGPT integration
- CompactMap height: 478px (standard ChatGPT Apps size)
- Automatic sync with ChatGPT's `displayMode` via `useDisplayMode()` hook
- Clicking ChatGPT's X button automatically collapses the map

## Technical Notes

**Component Architecture:** Map (orchestrator) follows the Album pattern - conditionally renders CompactMap or FullscreenMap based on fullscreen state. Supports both controlled and uncontrolled modes.

**SSR-Safe:** Uses lazy loading and client-side mounting checks to avoid SSR issues with Leaflet. A loading fallback is shown during hydration.

**Dependencies:**
- `leaflet` ^1.9.4 - Base mapping library
- `react-leaflet` ^4.2.1 - React components (React 18 compatible)
- `framer-motion` - Animation for Inspector panel
