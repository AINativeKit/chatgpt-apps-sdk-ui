## Usage

```tsx
import { CompactMap, FullscreenMap } from "@ainativekit/ui";
import type { RenderMarkerParams } from "@ainativekit/ui";

// Custom marker function
const renderMarker = (params: RenderMarkerParams) => (
  <svg width="32" height="32" viewBox="0 0 32 32">
    <circle
      cx="16" cy="16" r="14"
      fill={params.color}
      stroke="white"
      strokeWidth={params.isSelected ? '4' : '2'}
    />
  </svg>
);

<CompactMap locations={locations} renderMarker={renderMarker} />
```

Following industry-standard patterns from Material-UI DataGrid (`renderCell`) and Ant Design Table (`render`), the `renderMarker` function returns any React element—the library handles all Leaflet integration automatically.

**Three ways to customize:** Global `renderMarker` prop (all locations), per-location `renderMarker` (individual control), or hybrid with both (per-location overrides global).
