<Subtitle>Flexible list component for displaying data collections with rich metadata for ChatGPT Apps SDK</Subtitle>

## Usage

```tsx
import { List, ListItem } from "@ainativekit/ui";

<List
  items={contacts}
  renderItem={(contact) => (
    <ListItem
      key={contact.id}
      title={contact.name}
      subtitle={contact.email}
      media={contact.avatar}
    />
  )}
/>
```

## Technical Notes

**Accessibility:** ARIA roles, keyboard navigation (Tab, Enter, Space), screen reader support.

**Responsive:** Items adapt layout between mobile and desktop. Metadata moves inline on mobile.
