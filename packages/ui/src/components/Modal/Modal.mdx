## Usage

```tsx
import { Modal } from "@ainativekit/ui";

function MyComponent() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <button onClick={() => setOpen(true)}>Open</button>
      <Modal open={open} onClose={() => setOpen(false)}>
        <YourContent />
      </Modal>
    </>
  );
}
```

## Accessibility

- Uses `role="dialog"` and `aria-modal="true"`
- Escape key closes the modal by default
- Body scroll is disabled when modal is open
- Focus trap should be implemented in your content for full accessibility

## Notes

- Modal uses `position: fixed` and renders at the root level
- The close button is not included by default - add your own in the children content
- For responsive layouts, consider using `Modal` for mobile and `Sidebar` for desktop
