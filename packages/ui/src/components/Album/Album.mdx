## Usage

```tsx
import { Album } from "@ainativekit/ui";

// Uncontrolled (manages its own state)
<Album albums={albums} />

// Controlled (external state)
import type { AlbumType } from "@ainativekit/ui";

const [selectedAlbum, setSelectedAlbum] = useState<AlbumType | null>(null);

<Album
  albums={albums}
  selectedAlbum={selectedAlbum}
  onAlbumSelect={setSelectedAlbum}
/>
```

**Key Features:**
- Three component variants: Album (orchestrator), AlbumCarousel (carousel only), AlbumViewer (fullscreen)
- Keyboard navigation (arrow keys, ESC to close)
- Touch/swipe support via Embla Carousel
- Loading, error, and empty states built-in
- Responsive design with thumbnail sidebar on tablet+

## Component Selection Guide

| Component | Use When | Example |
|-----------|----------|---------|
| **Album** | Need carousel + viewer integration with auto state management | Photo gallery with fullscreen viewing |
| **AlbumCarousel** | Only need carousel display, custom viewer handling | Album picker without fullscreen |
| **AlbumViewer** | Custom viewer integration, standalone photo viewer | Modal photo viewer with external trigger |
| **AlbumCard** | Single album display with cover, title, and photo count | Album thumbnail in a grid or list |

## Data Types

### AlbumType

| Property | Type | Description |
|----------|------|-------------|
| `id` | `string` | Unique album identifier (required) |
| `title` | `string` | Album title (required) |
| `cover` | `string` | Cover image URL (required) |
| `photos` | `Photo[]` | Array of photo objects (required) |

### Photo

| Property | Type | Description |
|----------|------|-------------|
| `id` | `string` | Unique photo identifier (required) |
| `url` | `string` | Photo image URL (required) |
| `title` | `string` | Optional title/caption for the photo |
| `alt` | `string` | Alt text for accessibility |

## Technical Notes

**Component Architecture:** Album (orchestrator) follows the Map pattern - conditionally renders AlbumCarousel or AlbumViewer based on selection state. Supports both controlled and uncontrolled modes.

**Responsive Breakpoints:**
- Mobile (&lt;640px): Touch navigation, no thumbnail sidebar
- Tablet (≥640px): Thumbnail sidebar appears (160px width)
- Desktop (≥1024px): Maximum padding for optimal viewing

**Dependencies:**
- `embla-carousel-react` - Touch/swipe carousel
