## Usage

```tsx
import { Skeleton, ImageSkeleton } from "@ainativekit/ui";

// Basic skeleton
<Skeleton width={200} height={20} />

// Circular avatar
<Skeleton width={48} height={48} borderRadius="50%" />

// Image placeholder with icon
<ImageSkeleton width="100%" height={200} />
```

## Notes

- Uses CSS shimmer animation for loading effect
- Includes `aria-hidden="true"` for accessibility
- Supports both pixel values and CSS strings
- Used internally by Card, List, and Album components
