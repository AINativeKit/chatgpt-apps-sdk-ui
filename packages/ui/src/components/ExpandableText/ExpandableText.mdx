## Usage

```tsx
import { ExpandableText } from "@ainativekit/ui";

<ExpandableText
  text="Long description text that may exceed the visible area..."
  maxLines={3}
  expandLabel="Read more"
  collapseLabel="Read less"
/>
```

## Notes

- Uses CSS `line-clamp` for efficient text truncation
- Toggle button only appears when text is actually clamped
- Supports `aria-expanded` for accessibility
- Works with any text content including formatted descriptions
