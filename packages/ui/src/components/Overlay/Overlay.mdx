<Subtitle>Position content on top of images or media with customizable backgrounds</Subtitle>

## Usage

```tsx
import { Overlay } from "@ainativekit/ui";

<div style={{ position: 'relative', overflow: 'hidden' }}>
  <img src="photo.jpg" alt="Photo" />
  {/* Bottom overlay (default) */}
  <Overlay background="dark" height={56} align="center">
    <span style={{ color: 'white' }}>Caption</span>
  </Overlay>
</div>
```

## Notes

- Used internally by SummaryCard and PhotoCarousel components
- Requires parent container with `position: relative`
- Supports any CSS color value including gradients
- Content is vertically centered by default
